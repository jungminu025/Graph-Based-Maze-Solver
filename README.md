# Graph-Based Maze Solver

A Java application that solves maze navigation problems using Depth-First Search (DFS), recursion, and backtracking.

## Features
- Represents maze rooms and connections using graph data structures.
- Uses recursive DFS to find a valid path from entrance to exit.
- Supports weighted doors requiring a limited number of coins.
- Uses backtracking when a route does not lead to the exit.
- Integrates Java Swing visualization to display the maze-solving path.

## Technologies
- Java
- Graph Algorithms
- Depth-First Search (DFS)
- Recursion and Backtracking
- Object-Oriented Programming

## How to Run
Compile the Java source files with a JDK and run the application using a compatible maze input file:

`java Solve <maze-file>`
